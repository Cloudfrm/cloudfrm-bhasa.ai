dev only

Every frame below is the real Chat UI, loaded from /chat/states/frame — the same dashboard.html the desk serves at /. Each state is produced by calling the function the app itself calls, named under the state's title. Nothing here draws its own markup, so this page cannot drift away from the app: if a component changes, these change with it.

No desk data is read. In gallery mode the frame's three network helpers (getJSON, getPage, fetchSpeech) are redirected to fixtures defined in this file, so no conversation, ticket, message or speech call leaves the page. Nothing is written either.

The route is registered only when SUPPORT_ENV is not production. On a production deployment both this page and the frame path return 404.

One caveat worth knowing: each frame is its own viewport, so the app's responsive rules apply at the frame's width, not the browser's. These frames sit below the 960px breakpoint, so type, padding and stacking are the narrow-layout ones. The states themselves are identical; the desk's own proportions are not.
